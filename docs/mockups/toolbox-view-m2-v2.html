M2 · Toolbox view · v2

Changes from v1: ToolBox is now the centre of the map (it is the thing being watched). Rigel sits at the edge as one caller, with other agents alongside it. A 2D | 3D toggle sits in the header. 2D opens by default and the choice is remembered. If 3D cannot render, the view falls back to 2D and says why. Server names and counts are placeholders.

Fallback

If 3D cannot render (for example graphics support is missing), the view shows 2D, the toggle switches back to 2D, and a line reads: “3D unavailable here, showing 2D.” The reason shows on hover. The remembered choice stays 3D, so the next launch tries 3D again.
